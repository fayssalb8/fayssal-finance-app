# Smart Kitchen Finance

تطبيق Flutter لإدارة الدخل الشخصي في مطابخ المبيعات (واجهة عربية RTL بالكامل). يُحسب الراتب، الساعات الإضافية، البونص، الغياب، وعمولات المبيعات، ويُصدر تقارير PDF.

## الميزات

- **وضعان للتعويض**: راتب شهري + عمولة صغيرة، أو عمولة فقط (بدون راتب).
- **لوحة التحكم**: ملخص شهر العمل ببدئه المخصص (مثلاً 7 من كل شهر).
- **الوقت**: تسجيل الساعات الإضافية، البونص، والغياب (بالساعات أو بالأيام من رصيد العطلة).
- **المبيعات**: تسجيل البيع بالمساحة ونسبة العمولة، مع التوزيع المشترك بين الزملاء.
- **التقارير**: تقرير PDF (مشاركة أو طباعة) لمدى شهري أو سنوي أو مخصص.
- **تذكير يومي**: إشعار 18:00 في كل يوم عمل ما عدا الجمعة لتسجيل الساعات.

## الحسابات

| البند | القانون |
|---|---|
| سعر الساعة | الراتب الأساسي ÷ 174 |
| الساعة الإضافية | سعر الساعة × المعامل × الساعات |
| خصم الغياب بالساعات | سعر الساعة × الساعات (بدون معامل) |
| عمولة المبيعات | المساحة × سعر المتر × نسبة العمولة |
| صافي الراتب | الراتب − خصم الغياب + الإضافي |
| الإجمالي العام | صافي الراتب + البونص (العمولات منفصلة) |

توجد القوانين كلها في `lib/services/finance_service.dart` ومغطاة بالاختبارات.

## البنية

```
lib/
├── core/          # الثيم، المُنسّقات، أدوات التاريخ، المكوّنات الموحّدة
├── models/        # كائنات البيانات وإسنادها
├── data/          # AppDatabase (sqflite) مع الترحيلات v1 → v3
├── services/      # FinanceService، ReportPdfService، NotificationService
└── ui/            # الشاشات (لوحة تحكم، وقت، مبيعات، إعدادات، تقارير...)
```

## التشغيل

```bash
flutter pub get
flutter run
```

## الاختبار والجودة

```bash
flutter analyze          # لا توجد مشاكل
flutter test             # 13 اختباراً (الحسابات، التجميع، توليد PDF، إقلاع الواجهة)
dart format lib test
```

البيانات محلية في قاعدة SQLite على الجهاز، ولا تتطلب اتصالات خارجية أو صلاحيات حساسة.
