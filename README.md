# Smart Kitchen Finance (تطبيق إدارة مالية مطابخ المبيعات)

تطبيق Flutter حديث ومتقن لإدارة الدخل الشخصي في مطابخ المبيعات: الراتب الشهري، الساعات الإضافية، البونص، الغياب، عمولات المبيعات وتقارير PDF الاحترافية.

---

## المميزات الرئيسية (Key Features)

- **لوحة تحكم تفاعلية (Smart Dashboard)**: عرض فوري لصافي المستحقات، الساعات الإضافية، البونص، العمولات، ورصيد العطلة السنوية.
- **تعديل الراتب الفعلي الشهري**: إمكانية تعديل الراتب الفعلي لأي شهر معين مباشرة من لوحة التحكم مع خيار استعادة الراتب الأساسي الافتراضي بنقرة واحدة.
- **تتبع الهدف المالي الشهري**: تحديد هدف مالي مرجو مع حساب آلي للساعات الإضافية المتبقية لبلوغه.
- **نظامان مرنان للتعويض (Compensation Modes)**:
  1. **راتب شهري + عمولة**: حساب تلقائي لسعر الساعة من الراتب لخصم الغياب ومكافأة الساعات الإضافية.
  2. **عمولة فقط (بدون راتب)**: ساعات إضافية بسعر محدد متفق عليه، والغياب يُسجل فقط ضد رصيد العطلة السنوية بدون خصم مالي.
- **إدارة الساعات والغياب (Time Tracking)**:
  - تسجيل ساعات العمل الإضافية (تلقائي أو بسعر ثابت).
  - تسجيل الغياب بالساعات أو بالأيام (مربوط برصيد العطلة السنوية).
  - تسجيل البونص والمكافآت مع بيان السبب.
- **إدارة المبيعات والعمولات (Sales & Commissions)**:
  - احتساب عمولة المطبخ تلقائياً بناءً على المساحة وسعر المتر والنسبة (1.5% أو 2% أو نسبة مخصصة).
  - دعم المبيعات الفردية والمبيعات المشتركة مع الزملاء بنسب مئوية دقيقة.
  - معاينة لحظية مباشرة للعمولة أثناء كتابة المساحة.
- **تقارير PDF احترافية ومستقلة (Production-Ready PDF Reports)**:
  - **تقرير المستحقات**: الراتب، الساعات الإضافية، البونص، الخصومات مع تفصيل شهري وتوقيع رسمي، ودعم التمدد لصفحات متعددة دون قص أو أخطاء.
  - **تقرير عمولات المبيعات**: تقرير مالي منفصل لعمولات المبيعات لكل عملية بيع وإجمالي العمولات والمساحات.
  - دعم التصدير، الحفظ، والمشاركة المباشرة عبر واتساب أو البريد.
- **تذكير يومي ذكي (Daily Reminders)**: تنبيه يومي الساعة 18:00 لتسجيل ساعات العمل والغياب (باستثناء أيام العطلة الأسبوعية).

## البنية المعمارية (Architecture)

```text
lib/
├── core/               # الأدوات الأساسية، التنسيقات، التقويم والسمة الموحدة
│   ├── date_utils.dart # حسابات فترات العمل (مثلاً: من 7 إلى 6) وأسماء الأشهر العربية
│   ├── formatters.dart # معالجة وتحويل الأرقام (الفواصل العربية/الفرنسية والعملات)
│   ├── theme.dart      # لوحة الألوان والسمة البصرية الموحدة
│   └── widgets/        # البطاقات ومفاتيح اختيار شهور العمل
├── data/               # طبقة البيانات وقاعدة البيانات المحلية
│   └── app_database.dart # إدارة SQLite، المعاملات، والهجرات (Migrations)
├── models/             # نماذج البيانات (Settings, Sale, TimeRecord, Client, Colleague)
├── services/           # منطق العمليات والحسابات المالية والتقارير
│   ├── finance_service.dart      # القوانين المحاسبية والملخصات
│   ├── notification_service.dart # جدولة التذكيرات المحلية
│   └── report_pdf_service.dart   # توليد مستندات PDF ثنائية الاتجاه (RTL)
└── ui/                 # شاشات العرض وتدفق المستخدم
    ├── dashboard/      # لوحة التحكم الرئيسية
    ├── time/           # سجلات الوقت (إضافي / غياب / بونص)
    ├── sales/          # المبيعات والمبيعات المشتركة
    ├── reports/        # تصدير وطباعة التقارير
    ├── settings/       # ضبط الإعدادات وسعر المتر ونظام التعويض
    ├── clients/        # إدارة قائمة الزبائن
    ├── colleagues/     # إدارة قائمة الزملاء
    └── shell/          # شريط التنقل السفلي والربط المتزامن
```

## التشغيل والتطوير (Getting Started)

### المتطلبات
- Flutter SDK (الإصدار 3.24.x أو 3.41.x فما فوق)
- جهاز محاكي Android أو هاتف متصل

### التثبيت
```bash
# تثبيت الحزم والمكتبات
flutter pub get

# تشغيل الاختبارات
flutter test

# تشغيل التطبيق في وضع التطوير
flutter run
```
